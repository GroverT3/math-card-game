# 🧠 Math Card Game for Kids

A fun, fast-paced single-player card game designed to help kids practice math! The player solves equations using number and operator cards under a 30-second timer. Play 3 rounds, beat the clock, and get your best score!

## 🎮 Features
- Clickable number and operator cards (0–9, + − × ÷)
- Timed rounds (30 seconds each)
- Sound effects for correct answers
- "Play Again" button after each round
- Score tracker over 3 rounds
- Bonus points for using multiple operators!

## 🛠️ Built With
- HTML
- CSS
- JavaScript

## 🚀 How to Play
1. The game shows a math challenge.
2. Click number/operator cards to build your answer.
3. Press "Submit" to check if you're right.
4. Score as many correct answers as you can in 30 seconds.
5. Try to get a high score over 3 rounds!
